### 2. Фильтрация рассылок по ключевым словам

**Функция:** Автоматическая проверка истории перед отправкой кампании

**Описание:**  
Система извлекает ключевые слова из названия кампании и проверяет, не отправлялись ли ранее сообщения с этими словами в каждый чат. Если найдено совпадение - чат автоматически пропускается.

**Алгоритм:**
1. Извлечение ключевых слов из названия кампании (≥4 символа)
2. Исключение стоп-слов (`без`, `для`, `что`, `это`, ...)
3. Проверка истории каждого чата
4. Поиск ключевых слов в ранее отправленных сообщениях
5. Пропуск чата, если найдено совпадение

**Пример:**

**Название кампании:** `ПОЛАТИ БЕЗ ИЗОЛИРОВКИ ПЛЮС ПАКЕТ (12 сообщений)`

**Извлечённые ключевые слова:**
- `полати`
- `изолировки`
- `пакет`
- `плюс`
- `сообщений`

**Результат:**
- ✅ Кандидат **не получал** сообщений с этими словами → **отправляем**
- 🚫 Кандидат **уже получал** сообщение с "полати" → **пропускаем**

**Игнорируется:**
- Регистр: `ПОЛАТИ` = `полати` = `Полати`
- Знаки: `"Полати"` = `(Полати)` = `Полати,`
- Позиция: в начале, середине, конце текста

**Формат ответа API:**
```json
{
  "success": true,
  "sent": 45,
  "failed": 2,
  "skipped_by_campaign": 10,
  "skipped_by_keyword": 23,
  "keywords_checked": ["полати", "изолировки", "пакет", "плюс", "сообщений"]
}
```

**Расшифровка статистики:**
- `sent` - успешно отправлено
- `failed` - ошибки отправки
- `skipped_by_campaign` - уже отправляли эту точную кампанию
- `skipped_by_keyword` - найдены ключевые слова в истории (новое!)
- `keywords_checked` - список проверенных слов

**Логи:**
```
🔑 Кампания 'ПОЛАТИ БЕЗ ИЗОЛИРОВКИ...' - ключевые слова: ['полати', 'изолировки', 'пакет', 'плюс']
⏭️ Пропуск u2i-ABC: кампания уже отправлена
🚫 Пропуск u2i-XYZ: найдены ключевые слова - 'полати' в 'ПОЛАТИ', 'полати' в 'Работа в ПОЛАТИ'
✅ u2i-DEF: РАЗРЕШЕНО
📊 Итого: отправлено=45, ошибок=2, пропущено_по_кампании=10, пропущено_по_ключевым_словам=23
```

## 🔧 Технические детали

### База данных

**Используемые таблицы:**
- `applications` - отклики кандидатов
- `candidate_phones` - телефоны кандидатов
- `campaigns` - рассылочные кампании
- `campaign_messages` - сообщения кампаний
- `chat_campaigns` - история отправок (чат ↔ кампания)

**SQL запрос поиска по телефонам:**
```sql
SELECT DISTINCT 
    a.chat_id,
    a.candidate_name,
    cp.phone,
    a.vacancy_id,
    a.created_at,
    a.application_id
FROM applications a
JOIN candidate_phones cp ON a.application_id = cp.application_id
WHERE cp.phone IN (?, ?, ?, ...)
ORDER BY a.created_at DESC
```

**SQL запрос истории для фильтрации:**
```sql
SELECT DISTINCT cm.text, c.name
FROM chat_campaigns cc
JOIN campaign_messages cm ON cc.campaign_id = cm.campaign_id
JOIN campaigns c ON cc.campaign_id = c.id
WHERE cc.chat_id = ?
```

### Функции

**`extract_keywords(text, min_length=4)`**
```python
def extract_keywords(text, min_length=4):
    """Извлечение ключевых слов из текста."""
    # Убираем знаки, приводим к lowercase
    clean_text = re.sub(r'[^а-яёa-z0-9\s]', ' ', text.lower())
    
    # Разбиваем на слова и фильтруем
    words = [word for word in clean_text.split() if len(word) >= min_length]
    
    # Исключаем стоп-слова
    keywords = [word for word in words if word not in stop_words]
    
    return list(set(keywords))
```

**`check_keyword_in_history(chat_id, keywords)`**
```python
def check_keyword_in_history(chat_id, keywords):
    """Проверка ключевых слов в истории чата."""
    # Загружаем историю из БД
    sent_messages = db.query(chat_id)
    
    # Ищем каждое ключевое слово
    for message_text, campaign_name in sent_messages:
        for keyword in keywords:
            pattern = r'\b' + re.escape(keyword) + r'\b'
            if re.search(pattern, message_text):
                return True, [(keyword, campaign_name)]
    
    return False, []
```
